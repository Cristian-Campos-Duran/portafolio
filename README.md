# Portafolio — Cristian David Campos

Portafolio estático de una pantalla, con una galería de proyectos, servicios y procesos reales de edición.

Publicación: Settings → Pages → GitHub Actions. Consulta `docs/PUBLICAR_GITHUB_Y_ACTUALIZAR_CV.md`.

CV: sustituir `public/assets/documents/Cristian_David_Campos_CV.pdf` conservando el nombre.

Los MP4 grandes se reconstruyen automáticamente desde `media-source/` al compilar. No se recomprimen.

Desarrollo local opcional: `npm ci` y `npm run dev`. Compilación: `npm run build`. Node.js 22.13 o posterior.
